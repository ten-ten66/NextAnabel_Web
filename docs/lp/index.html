01自己処理の悩み

自己処理の手間や、肌への負担が気になっていませんか。

  • 剃っても、数日でまた気になる

    カミソリで処理しても数日で伸びてくるため、処理にかける時間が少しずつ積み重なります。

  • カミソリ負けや、毛抜きのあとの赤み

    自己処理をくり返すうちに、肌が赤くなったり、ぶつぶつが出たりすることがあります。

  • 背中やうなじは、自分では届きにくい

    見えにくい部位ほど処理が難しく、剃り残しも気になりやすくなります。

  • 結局、総額でいくらかかるのか

    1回の料金だけを見ても、通い終えるまでにかかる費用と期間はわかりにくいものです。

医療レーザー脱毛は、医療機関で医師の管理のもとに行う脱毛です。自己処理の回数を減らしたい方の選択肢のひとつとして、まずはしくみと費用の全体像を確かめてください。

02医療脱毛のしくみ

数回に分けて通うのは、毛に「周期」があるから。

1レーザーは、毛の黒い色素に反応します

医療レーザーの光は、毛に含まれる黒い色素（メラニン）に吸収されて熱に変わります。この熱で、毛を作り出す毛根の組織にダメージを与え、毛が生えにくい状態をめざします。

2作用しやすいのは「成長期」の毛

毛は「成長期」「退行期」「休止期」をくり返しながら生え替わっています（毛周期）。レーザーが作用しやすいのは、毛根とつながっている成長期の毛です。1回の照射で反応するのは、その時点で成長期にある一部の毛のため、間隔をあけて数回照射します。

06リスク・副作用

施術を受ける前に、必ずお読みください。

医療レーザー脱毛には、次のようなリスク・副作用があります。症状が出たときは、医師が診察して対応します。

  • 赤み・腫れ

    照射後に赤み・腫れ・ほてりが出ることがあります。多くは数時間〜数日で落ち着きます。長引く場合は医師が診察します。

  • 毛嚢炎

    毛穴に炎症が起こり、ニキビのようなぶつぶつが出ることがあります。必要に応じて塗り薬などを処方します。

  • 硬毛化・増毛化

    まれに、照射した部位やその周りの毛が太く・濃くなることがあります。背中・うなじ・二の腕などで起こりやすいとされ、照射の方法を変えるなどして対応します。

  • やけど

    肌の状態や日焼けの程度によって、やけど（水ぶくれなど）が生じることがあります。テスト照射と出力の調整で予防に努めます。

  • 色素沈着

    炎症のあとに、肌が茶色っぽく色づくことがあります。時間とともに薄くなることが多いものの、数か月かかる場合があります。

  • 照射時の痛み

    輪ゴムで弾かれたような痛みを感じることがあり、感じ方には個人差があります。冷却しながら照射し、必要に応じて麻酔クリームを使用します。麻酔クリームは有料で、1部位 3,300円（税込）です。

ダウンタイム

照射後の赤みやほてりは、数時間〜数日で落ち着くことが多いです。照射当日は、長時間の入浴・サウナ・飲酒・激しい運動など、体が温まることは控えてください（シャワーは可能です）。照射の前後は日焼けを避けてください。

照射できない方

  • 妊娠中、または妊娠の可能性がある方
  • 照射する部位に強い日焼けがある方
  • 光線過敏症の方
  • 照射する部位に傷・炎症、治療中の皮膚の病気がある方

照射の前にご相談いただきたい方

  • 授乳中の方
  • 光線過敏を起こしやすいお薬を服用中の方
  • ケロイド体質の方
  • てんかんの発作を起こしたことがある方
  • 照射する部位にタトゥー・アートメイク・濃いほくろがある方（その部分を避けて照射します）

照射できるかどうかは、診察のうえ医師が判断します。
