# 白磁スキンクリニック（HAKUJI SKIN CLINIC）

南青山の美容皮膚科を想定した、**架空のクリニック**のコーポレートサイトです。クリニック名・医師名・住所・電話番号・料金はすべて架空で、実在の医療機関・人物とは関係ありません。

## コンセプト「白磁」

「納得してから、はじめる肌治療。」を軸に、施術を受けるかどうかを決めるための情報（費用の総額・回数の目安・リスク）を、施術の前にすべて示すクリニックとして設計しました。

- **色**: 白磁の地（`#F7F8F6`）に、呉須の青（`#2B4C8C`）を予約ボタン・リンク・小さな印にだけ使う。青磁色・霧色の淡い面でセクションを切り替え、罫線は細く。
- **書体**: 見出しと価格の数字は Shippori Mincho B1、本文は Zen Kaku Gothic New（2ファミリー・3ウェイト）。
- **組版**: 広い画面ではセクション名を縦書きで左に置き、本文側は非対称に組む。ファーストビューのコピーも縦書きにし、器の裏の窯印のような「白磁」の印を添える。
- **動き**: 白磁の画像の上で、呉須と青磁色のもやがゆっくり揺れる「釉薬のゆらぎ」（Canvas）。止まった状態でも完成した画面になるようにしている。

色・余白・書体の値は `tokens/skin-clinic.tokens.json` と一致させ、CSS ではカスタムプロパティだけを使っています。

## ページ構成

| ページ | ファイル | 主な内容 |

| 料金表 | `price.php` | 悩み別のタブ（税込の料金表）、診察料・麻酔・お薬、お支払い方法、キャンセル規定、クーリング・オフと中途解約 |

| よくあるご質問 | `faq.php` | 予約・費用・施術・キャンセル・未成年（親権者の同意書）・妊娠中や授乳中など7分類 |

## 見どころ（クリニックの方へ）

- **費用とリスクを並べて表示**: 施術詳細では、税込の料金表のすぐ隣に、主なリスク・副作用を本文と同じ文字サイズで示します。料金表・施術一覧・トップのカードにも、価格と一緒に主なリスクを添えています。
- **総額がわかる料金表示**: すべて税込の総額。初診料・再診料・麻酔代・お薬代も掲載し、トップでは「はじめてIPL光治療を受ける場合」のお会計の例を示しています。
- **コース契約の案内**: 期間が1か月を超え、5万円を超えるコースに＊印を付け、クーリング・オフ（8日以内・書面または電磁的記録）と中途解約を同じページで案内します。部位を組み合わせて5万円を超える場合も対象になることを明記しています。
- **未承認医療機器の表記例**: HIFU のページに、表示が必要な5項目の記載例を置いています（架空のサンプルであり、実在の機器の承認状況を示すものではありません）。
- **医師の監修と最終確認日**: 施術ページの冒頭に「監修：院長 汐見 透子（皮膚科専門医）／最終確認日」を表示し、構造化データ（MedicalWebPage の reviewedBy・lastReviewed）にも反映しています。
- **本日の受付状況**: 診療時間のデータから「診療中／まもなく受付終了／本日の受付は終了しました／本日休診」をリングで表示し、1分ごとに更新します。祝日・年末年始も休診として扱い、次の診療日を案内します。
- **予約フォーム**: 定休日（木曜）を選ぶとその場で知らせ、送信時にも受け付けません。祝日を選んだ場合は、クリニック宛てのメールに「※休診日」と表示されます。入力者への自動返信メールには、ご相談内容などの自由記述を含めません。

## 見どころ（制作会社の方へ）

- **データ駆動のテンプレート**: 施術・料金・FAQ・医師・お知らせは `data/*.php`（純粋な配列）で管理し、各ページはそれを組み立てるだけです。医療脱毛の料金は LP と共通の `data/hair_removal.php` から読み込み、料金の二重管理を避けています。
- **表現チェックとの対応**: `data-disclosure="price / risks / sessions / downtime / contact / cooling-off"`、`data-disclosure-group`、`data-reviewed-by`、`data-course="qualifying"`、`data-unapproved` を、ガイドラインの必須表示に合わせて出力しています。どれも `details` の中には入れていません。特定継続的役務に当たるかどうかは `is_qualifying_course()`（期間1か月超かつ5万円超）で判定します。
- **段階的強化**: JavaScript がなくても本文はすべて読めます。絞り込みのボタンは JavaScript が動くときだけ表示し（`<noscript>` の中の CSS で隠す）、料金表のタブは「ページ内リンクの一覧＋全パネル」から WAI-ARIA のタブに置き換えます。メニューボタンは、JavaScript がなければフッターのメニューへのリンクとして働きます。
- **アクセシビリティ**: モバイルのメニューは `dialog` 要素（`showModal`）で背面を操作不可にし、Tab の循環・Esc で閉じる・ボタンへのフォーカス復帰に対応。タブは矢印キー・Home/End、FAQ は `details`/`summary`。フォームのエラーは `aria-invalid`・`aria-describedby` と、項目へのリンク付きのエラー一覧で伝えます。操作できる要素は 44px 以上です。
- **動き**: 動かすのは `transform` と `opacity` が中心です（FAQ の開閉だけは、操作に応じた短い演出として例外的に高さを補間）。絞り込みは FLIP（Web Animations API）、ページ間は View Transitions（押したカードの画像だけに名前を付けて、詳細ページの画像へつなぐ）。Canvas は 30fps 以下で、画面外やタブの非表示時は止まり、5秒を超えて動くため一時停止ボタンを付けています。`prefers-reduced-motion: reduce` ではいずれも動かしません。
- **パフォーマンス**: JavaScript は共通の `main.js`（約19KB）と、トップだけの `home.js`、予約ページだけの `contact.js` に分け、どのページも 40KB 未満です。画像は WebP（最大でも十数KB）で、ファーストビュー以外は遅延読み込み。日本語フォントはビルド時にサイト内で使う文字だけに絞られます（`tools/fonts.php`）。
- **フォームの安全性**: サーバー版は `Core\Form\FormFlow`（CSRF トークン・ハニーポット・送信までの時間・送信間隔の制限・PRG）を使用。値は確認画面の hidden ではなくセッションから送信します。

## 技術メモ

### ファイル構成

```
sites/skin-clinic/
├─ _init.php / _helpers.php     初期化と、このサイト専用の表示用関数
├─ build.config.php             静的ビルドの設定（施術詳細は data/treatments.php の slug ごと）
├─ *.php                        各ページ
├─ partials/                    head・header（ドロワー）・footer・カード・料金表・地図など
├─ data/                        site.php（基本情報・診療時間・休診日）、treatments.php、hair_removal.php（LPと共通）、
│                               categories.php、fees.php、faq.php、doctor.php、news.php、nav.php
├─ assets/css/style.css         トークン → ベース → レイアウト → 部品 → ページ → ユーティリティ → 動き
├─ assets/js/main.js            全ページ共通（ヘッダー、ドロワー、絞り込み、タブ、アコーディオンほか）
├─ assets/js/home.js            トップのみ（受付状況のリング、釉薬のゆらぎ）

├─ assets/img/                  生成画像（WebP）、favicon.svg、ogp.png
└─ og.html                      OGP 画像の元（node tools/og-image.mjs skin-clinic）
```

### よく変更する箇所

- **料金**: `data/treatments.php`（医療脱毛は `data/hair_removal.php`）。税込の整数で書けば、表示は「22,000円（税込）」になります。
- **休診日**: `data/site.php` の `closed_dates`（祝日・年末年始。年に1回更新）。曜日の診療時間は `schedule`。受付状況・本日の強調・フォームの判定がすべてここを参照します。
- **監修日**: 各施術の `reviewed`。

### 表示の確認

- 受付状況はURLに `?now=2026-10-06T18:10` を付けると、その日時（日本時間）として表示できます。
- 静的版のフォームは送信せず、入力値の検証・確認画面・完了画面を画面上で再現します（入力値は `textContent` で表示）。

### ビルドと検証

```bash
php tools/build.php --site=skin-clinic --out=build/skin-clinic   # 書き出し＋表現チェック
find sites/skin-clinic -name '*.php' -print0 | xargs -0 -n1 php -l
npx html-validate "build/skin-clinic/skin-clinic/**/*.html"
php -S 127.0.0.1:8201 -t sites/skin-clinic                        # サーバー版（フォームの送信を確認）
```

サーバー版のメールは、環境変数 `MAIL_TRANSPORT=native` がなければ `storage/mail.log` に書き出されます。

### 既知の制約

- フォームのサーバー側の検証では、定休日（曜日）は受け付けませんが、祝日は判定しません（案内文とメールの「※休診日」表示で補っています）。
- 院内写真・医師写真は、撮影素材に差し替える前提の仮の画像です。
