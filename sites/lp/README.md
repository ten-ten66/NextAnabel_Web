# 白磁スキンクリニック 医療脱毛LP（sites/lp）

架空の美容皮膚科「白磁スキンクリニック」の、医療レーザー脱毛の広告用ランディングページです。
コーポレートサイト（`sites/skin-clinic/`）と医院情報・料金データを共有しています。

## コンセプト

**「医療脱毛は、総額と回数を知ってから。」**

広告（検索・SNS）から来る、医療脱毛を検討し始めた人が対象です。閲覧の中心はスマートフォンです。
脱毛の検討で一番の不安は「結局いくらかかって、何回通うのか」。値引き・体験談・期限の煽りに頼らず、
**税込の総額・回数の目安・リスクを先に見せきること**を、予約につなげる理由そのものにしています。

このサンプルは2種類の読み手を想定しています。

| 読み手 | 見てほしいところ |
|---|---|
| 広告用LPを発注するクリニック | 医療広告ガイドラインを踏まえた設計（必須表示・禁止表現・クーリング・オフ）のまま、予約の導線を強くできること |
| LPの品質を見極める制作会社 | 情報設計、シミュレーター、入力フォームの作り込み（EFO）、計測の仕込み、表現チェックの自動化 |

## ページ構成（1ページ）

| # | セクション | 役割 | 見どころ |
|---|---|---|---|
| FV | 見出し・CTA・安心材料 | 約束を一文で伝え、予約と試算の2つの入口を置く | 明朝の見出し、事実だけの安心材料3点、5回・約10か月の目安カード、PCでは人体図の挿絵 |
| 01 | 自己処理の悩み | 共感（誇張しない） | 4つの具体的な負担。最後に「しくみと費用の全体像を確かめて」と次へ橋渡し |
| 02 | 医療脱毛のしくみ | なぜ数回通うのかを納得してもらう | 皮膚の断面と毛周期の図（画面に入ると1回だけ光が毛根へ届く演出）、回数・期間の目安 |
| 03 | 料金シミュレーター | 自分の総額を知る（このLPの主役） | 人体図⇄部位一覧の双方向同期、セット料金の自動適用、税込総額のカウントアップ |
| 04 | 料金表 | 全体の料金を静的に確認 | 費用とリスクを同じ枠に並べる、料金に含まれるもの・別途かかるもの、クーリング・オフ |

| 06 | リスク・副作用 | 全文を常に表示（折りたたまない） | 6項目、ダウンタイム、照射できない方・相談が必要な方、監修医 |
| 07 | よくある質問 | 予約前の最後の不安を解消 | ボタン＋aria-expanded のアコーディオン。ページ内検索で閉じた回答も見つかる（hidden="until-found"） |
| 08 | 予約フォーム | カウンセリング予約（無料） | 入力→確認→完了、シミュレーターからの引き継ぎ、サーバー版は JSON API に送信 |
| — | フッター | 問い合わせ先・診療時間・監修 | コーポレートサイトと同じ NAP、監修医と最終確認日 |

## 割引に頼らないCV設計

- **迷いの原因を順番に消す**: 共感 → しくみ（回数の理由）→ 試算（自分の総額）→ 料金表（全体）→ 流れ → リスク → FAQ → 予約。
  価格の前に「なぜ5回・約10か月なのか」を説明し、総額を見ても驚かない状態をつくります。
- **安心材料は事実だけ**: 「医師が診察し、照射プランを決定」「肌トラブル時の診察・お薬は無料（照射が原因と医師が判断した場合）」
  「料金はすべて税込の総額で表示」「その日に契約を決める必要はありません」。
- **CTAの置き場所**: FV（予約／試算）、ヘッダー、試算結果（この内容で予約）、固定CTA（試算額つき）、予約フォーム、電話。
- **試算から予約への引き継ぎ**: 「この内容でカウンセリングを予約」で、選んだ部位を希望部位に入力してフォームへ移動。
  確認画面には参考の総額（税込）も表示します。
- **使わないもの**: 限定・キャンペーン・%OFF・月額表示・カウントダウン・ランキング・体験談・笑顔のストック写真・赤い「限定」バッジ。

## 料金シミュレーター

- **データ**: `sites/skin-clinic/data/hair_removal.php`（コーポレートサイトと共通・税込）。
  同じデータから、静的な料金表（JavaScript なしでも読める）と、計算用の JSON（`<script type="application/json" id="plan-data">`、
  `JSON_HEX_TAG` などでエスケープ）を出力します。料金を変えるときはこのファイルだけを直します。
- **計算**: 選んだ部位の「5回コース」「1回」の料金を合計します。セット（`sets`）に含まれる部位をすべて選んだときは
  「セット料金＋残りの部位」を候補にし、総額がもっとも低い組み合わせを採用して「セット料金で計算しています」と表示します。
  PHP（`lib/plan.php` の `lp_estimate()`：院内向けメールの参考額）と JavaScript（`estimate()`）は同じ計算です。
  - 例: 全身（顔・VIOを除く）の9部位 → 297,000円（税込）、さらに顔を追加 → 297,000円＋74,800円＝371,800円（税込）、
    全11部位 → 全身（顔・VIOを含む）418,000円（税込）
- **表示**: 5回コース総額（税込）を主に、1回あたりの料金（コースにせず1回ずつ受ける場合）を従に、通院回数・期間の目安、
  主なリスク・副作用を併記します。総額が5万円を超え、期間が1か月を超えるときはクーリング・オフの案内を出します。月額表示はしません。
- **人体図**: 単純な図形で描いた前面・背面（`partials/figure.php`）。どちら側で選べるかはデータの `side` に従い、
  反対側にも見える部位（腕・脚など）は選択状態だけを淡く映します。小さな部位（ワキ・手・足）は透明な当たり判定を広げています。
- **アクセシビリティ**: 操作の正は部位のチェックボックス一覧です。人体図の部位は JavaScript が動くときだけ
  `role="button"`・`aria-pressed`・`aria-label` を持つボタンになり、一覧と双方向に同期します（Enter / Space で操作可）。
  前面・背面の切り替えは `aria-pressed` のボタン。総額のカウントアップは表示だけで、読み上げは確定値を
  `aria-live="polite"` で1回だけ（連続操作中は700ms待って最後の値のみ）。
- **JavaScript なし**: 前面・背面を並べて表示し、試算欄に「料金表をご覧ください」と案内します。料金表で全情報を確認できます。

## 予約フォーム（EFO）

- 入力 → 確認 → 完了をページ内で切り替え（`aria-current="step"`）、画面ごとに見出しへフォーカスを移動。
- 必須6項目（お名前・電話番号・メールアドレス・第1希望日・時間帯・同意）。希望部位とご質問は任意。
- 電話番号・メールアドレスは全角を半角に、長音やダッシュをハイフンに自動で整えます。
- 検証は入力欄を離れたとき（入力があった欄のみ）。エラー表示後は直した時点で消えます。
  送信時はエラー一覧（件数・各項目へのリンク）を出してフォーカスを移し、各欄に `aria-invalid`・`aria-describedby` を付けます。
- 第1希望日は**クリニックのタイムゾーン（Asia/Tokyo）の日付**で翌日〜60日後。休診日（木曜）は選んだ時点で知らせます（サーバーでも検証）。
- 時間帯の選択肢と最終受付（終了の30分前）は `site.php` の診療時間から組み立てます。
- 個人情報の取り扱いは要約をその場で読め、全文はコーポレートサイトのプライバシーポリシーへリンクしています。

### サーバー版（`api/reserve.php`）

`index.php` が `Core\Form\Session` を開始し、`Csrf::token()` を `<meta name="csrf-token">` に出力、`Guard::stamp('lp')` で表示時刻を記録します。
JavaScript は JSON を `fetch` で送信します。API の処理順と応答は次のとおりです。

| 順 | 検査 | 応答 |
|---|---|---|
| 1 | POST 以外 | 405（`Allow: POST`） |
| 2 | 送信元が同じオリジンか（`Http::sameOrigin()`） | 403 |
| 3 | CSRF トークン | 403 |
| 4 | ハニーポット・表示から3秒以内（`Guard::isBot()`） | 200（成功に見せて何もしない） |
| 5 | 入力検証（`Validator`＋休診日） | 422 `{ok:false, errors}` |
| 6 | 送信間隔・回数（`RateLimit`：30秒・1時間5回） | 429 |
| 7 | 院内向けメール＋自動返信（`MailerFactory::create()`） | 200 `{ok:true}` |

自動返信には、申込者が自由に書ける値（お名前・ご質問）を入れません。第三者のアドレスを入力して任意の文面を送らせる
「踏み台」に使われるのを防ぐためです（受付内容は選択肢と日付だけを記載）。院内向けメールには全項目と参考の総額を入れます。
メールは既定で `storage/mail.log` に記録され、`MAIL_TRANSPORT=native` のときだけ実際に送信します。
API が返すエラー文はブラウザ側の同じ文言で表示します（Webフォントのサブセットに含まれる文字で表示するため）。

### 静的版（GitHub Pages・Artifact）

`<html data-env="static">` のときは送信せず（fetch を呼ばない）、確認 → 完了まで進み、「サンプルのため送信されません」と明示します。
JavaScript が動かない場合は送信ボタンを無効のままにし、電話での予約を案内します。

## 固定CTA

ファーストビューを過ぎると画面下に表示し、予約フォームと試算結果カードが見えている間は隠します（IntersectionObserver）。
部位を選ぶと「試算 2部位 5回コース総額 94,600円（税込）」のように試算額を添えます。iPhone のホームバーを避ける
`env(safe-area-inset-bottom)` に対応。隠れている間は `inert` にしてフォーカスが入らないようにしています。PCでは右下に浮かぶ小さな帯になります。

## 計測（dataLayer）

タグ（GTM・GA）は読み込まず、`window.dataLayer` にイベントを積むだけにしています。導入時は GTM のカスタムイベントで受けます。

| イベント | パラメータ | タイミング |
|---|---|---|
| `cta_click` | `location`（`fv` / `fv-simulator` / `header` / `header-tel` / `simulator` / `dock` / `dock-tel` / `reserve-tel` / `footer-tel`） | `data-cta` を持つリンクのクリック |
| `simulator_change` | `parts_count`・`total`（税込総額）・`set_id` | 部位の選択が変わったとき（500ms 待って最後の状態） |
| `form_start` | — | フォームへの最初の入力 |
| `form_submit` | `mode`（`server` / `static`）・`parts_count` | 申し込みの完了 |

## 表現と必須表示（医療広告ガイドラインを踏まえた設計）

`build.config.php` は `profile => 'medical'`、ページは `kind => 'treatment'` で、`tools/lint-compliance.php` が必須表示まで検査します。

- **費用とリスクを隣に**: 料金表と「主なリスク・副作用」を同じ `data-disclosure-group` に並べ、本文と同じ文字サイズで表示。試算結果にもリスクを併記。
- **必須表示**: 費用（`price`）、回数・期間の目安と個人差（`sessions`）、リスク・副作用（`risks`）、ダウンタイム（`downtime`）、
  問い合わせ先（`contact`）、監修医と最終確認日（`data-reviewed-by`）。いずれも折りたたみ（details）の外。
- **特定継続的役務**: 5回コースは約10か月。5万円を超えるコースに `data-course="qualifying"`（料金表の※印）を付け、
  クーリング・オフの案内（8日以内は書面または電磁的記録で解除可、8日経過後も中途解約可・法令の上限内で解約手数料）を常に表示。
  複数部位の合計が5万円を超える場合も対象になる旨と、試算額が5万円を超えたときの案内も出します。
- **価格はすべて税込**: `tax_in()` か、表の `data-price-context="tax-included"`＋見出しの「（税込）」。基準額は「5万円」と表記。
- **書かない**: 最上級、最安、永久、効果の保証、キャンペーン・割引・月額、体験談・口コミ、「痛くない」「ダウンタイムなし」など。
  痛みは「感じ方に個人差がある」「冷却しながら照射し、必要に応じて麻酔クリーム（有料）」と書きます。
- **架空の注記**: 先頭とフッターに表示（`data-lint-ignore`）。

医院情報（NAP）は `data/site.php` が `skin-clinic/data/site.php` を読み込んで上書きするだけなので、両サイトで食い違いません。
構造化データは `MedicalWebPage`（`reviewedBy`・`lastReviewed`・`about: MedicalProcedure`）と、コーポレートサイトと同じ `@id` の `MedicalClinic` です。

## 技術

```
sites/lp/
├─ _init.php            初期化（core/bootstrap.php・設定・lib の読み込み）
├─ build.config.php     静的ビルドの設定（api/ は含めない）
├─ index.php            ページ本体（セクションは partials/ に分割）
├─ api/reserve.php      予約受付 API（サーバー版のみ）
├─ lib/plan.php         料金データの参照・試算・医院情報の整形
├─ lib/reservation.php  フォーム定義・検証・メール文面（画面と API で共通）
├─ data/site.php        サイト設定（コーポレートサイトの設定を読み込んで上書き）
├─ data/lp.php          本文データ（悩み・流れ・リスク・FAQ など）
├─ partials/            head / header / footer / 各セクション / 人体図 / しくみの図 / アイコン
├─ assets/css/style.css トークン（tokens/lp.tokens.json と一致）＋ FLOCSS
├─ assets/js/main.js    依存なし（約34KB）
├─ assets/img/          fv-bg.webp・section-bg.webp（tools/gen_visuals.py）、ogp.png、favicon.svg
└─ og.html              OGP画像（1200×630）の原稿
```

- **動き**: 止まった状態が完成形。FV の読み込み演出（約1.1秒で完了）、しくみの図（画面に入ったとき1回）、総額のカウントアップ、
  人体図の前面・背面の切り替え、部位を選んだときの小さな弾み、固定CTAのスライド。動かすのは transform と opacity だけで、
  `prefers-reduced-motion: reduce` ではすべて止めます（遷移時間も 0 に）。
- **書体**: Shippori Mincho B1（600・FVの見出し）と Zen Kaku Gothic New（400 / 700 / 900）。ビルド時に `tools/fonts.php` がサブセット化します。
- **色**: すべて `tokens/lp.tokens.json` の色から（影・半透明は `color-mix()` で合成）。ライトテーマ固定。

## 実案件にするときの差し替え

- 料金・回数: `sites/skin-clinic/data/hair_removal.php`（部位を増やしたら `partials/figure.php` に形を追加。形がなくても一覧・料金表・計算には出ます）
- 本文・最終確認日: `data/lp.php`
- メール: `MAIL_TRANSPORT=native` と送信元ドメインの SPF / DKIM / DMARC
- 計測: GTM のコンテナを追加し、上記イベントをトリガーにする
